# 回归测试

运行全部测试：

```bash
make test
```

默认使用 macOS `/bin/bash`，覆盖系统 Bash 3.2 的正式执行路径。已安装现代 Bash 时可运行：

```bash
TEST_BASH="$(brew --prefix bash)/bin/bash" make test
```

测试使用 Python 标准库 `unittest`，不需要额外 Python 包。每个用例建立临时仓库副本和家目录，安装、清理、SDKMAN 和编辑器命令由桩命令替代；测试环境不继承本机的凭证、Homebrew 或运行时环境变量。测试中的文件替换会真实执行，但目标都在临时目录中。

当前共 40 项测试。来源检测用例会执行真实的仓库 Ruby 检测脚本，配合 `fixtures/homebrew/` 中的 Homebrew 接口桩；Brewfile 样例由 Ruby 求值，已安装包与信任接口使用测试数据。解释器依次取 `TEST_RUBY`、Homebrew 自带的 portable Ruby（与 `brew ruby` 实际运行脚本的版本一致）、PATH 中的 `ruby`，都没有时跳过这些用例。

接口桩不能发现 Homebrew 内部接口的变化，因此另有 `test_finder_against_real_homebrew_api`：本机装有 Homebrew 时，用真实 `brew ruby` 只读运行检测脚本，验证各种合法写法与信任声明不误报；本机装有第三方包时，再取其中一个验证短名称、无授权完整名称会命中，tap 授权、按包授权会放行。该用例只读，未安装 Homebrew 时跳过。

覆盖内容：

- 预演处于终端环境时也不能接收删除确认。
- 符号链接、悬空链接、链接父目录和重复备份的安全行为。
- 系统 Bash 的正式 quickstart、full profile 及失败传播。
- 废弃 tap、官方源范围、core/full 子集关系与可选第三方来源。
- Homebrew 导出、扩展导出失败时保留旧文件，并继续输出汇总。
- 信任重置确认、有效快照先于清理、失败或损坏快照阻止清理。
- 第三方 formula 与 cask 的实际来源、完整名称和清单信任声明；按包、按 tap 授权以及包类型隔离。
- 名称中的 `+`、`.`、单引号、缩进、选项、条件和注释；清单解析或来源读取失败时禁止快照及清理。
- 迁移命令在 Bash 和 zsh 下保留中文、空格、单双引号、美元符号及反引号等路径字符，不执行路径中的命令替换；实际调用始终落到 brew 桩。
- 缺少命令、安装失败、Maven 失败及重复运行的状态处理。
- pnpm 不依赖 Corepack、版本基线覆盖、本地镜像加载。
- dry-run 不写家目录、不修改仓库，也不执行安装命令。

新增用例应检查具体结果，例如旧内容是否保留、后续危险命令是否未执行，而不是只检查退出码。当前测试不能代替真实新机恢复、GUI 登录和软件安装兼容性验收。
