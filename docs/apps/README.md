# 应用文档目录说明

本目录记录 GUI 应用、IDE 和编辑器。

| 文件 | 用途 |
|------|------|
| `ide.md` | JetBrains、VS Code、Cursor、Zed 等编辑器 |
| `gui-apps.md` | 普通 GUI 应用用途清单 |
| `app-store.md` | App Store 应用与 mas 策略 |

## 编写原则

- 对开发环境有影响的工具写独立小节。
- 普通应用只说明用途，不写过长手册。
- 不记录登录态、授权文件、商业许可、个人账号。
- 快捷键和常用入口同步到 [../reference/cheatsheet.md](../reference/cheatsheet.md)。
