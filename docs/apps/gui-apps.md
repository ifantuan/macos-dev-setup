# 应用清单说明

## 说明

本文只记录普通 GUI 应用的用途，不为每个应用编写深度手册。会影响开发环境一致性的工具已经拆到独立手册。

App Store 应用不默认进入自动安装路径，原因和 `mas` 策略见 [app-store.md](app-store.md)。
