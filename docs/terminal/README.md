# 终端文档目录说明

本目录记录终端、Shell、tmux、Ghostty 等交互环境。

| 文件 | 用途 |
|------|------|
| `shell.md` | zsh、Starship、tmux、fzf、zoxide、Yazi |
| `ghostty.md` | Ghostty 配置、快捷键、操作和排障 |

## 编写原则

- 快捷键先写本仓库配置中的实际行为。
- 命令优先可复制执行。
- 复杂解释放专题手册，高频操作同步到 [../reference/cheatsheet.md](../reference/cheatsheet.md)。

修改 `configs/zsh/zshrc` 或 `configs/ghostty/config` 后，要同步检查本目录文档。
