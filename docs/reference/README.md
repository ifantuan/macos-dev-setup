# 参考资料目录说明

本目录放跨主题、可快速查阅的资料。

| 文件 | 用途 |
|------|------|
| `cheatsheet.md` | 常用命令与快捷键速查 |
| `troubleshooting.md` | 常见问题排障 |
| `official-links.md` | 官方资料入口 |

## 编写原则

- `cheatsheet.md` 只放高频命令和快捷键，不写长篇解释。
- `troubleshooting.md` 按问题分类，先给定位命令，再给处理命令。
- `official-links.md` 只集中放链接，不替代本仓库手册。

如果某个工具需要大量说明，优先在对应专题目录新增手册，再从这里链接过去。
