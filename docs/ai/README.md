# AI 编码工具目录说明

本目录记录 Codex、Claude Code 和其他 AI 编码工具的使用方式。

| 文件 | 用途 |
|------|------|
| `overview.md` | AI 编码工具分工和通用原则 |
| `codex.md` | Codex CLI / App 使用、审查、MCP、排障 |
| `claude-code.md` | Claude Code 使用、权限、MCP、排障 |

## 编写原则

- 命令以当前工具 `--help` 为准。
- 不记录真实 API key、MCP token、私有服务地址。
- 高频命令同步到 [../reference/cheatsheet.md](../reference/cheatsheet.md)。
- 认证和网络问题同步到 [../reference/troubleshooting.md](../reference/troubleshooting.md)。
